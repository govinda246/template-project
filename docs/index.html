まず、全体像をつかむ

この環境は「ゲームを作る部屋」と「外との出入口を管理する門番」の2つが中心です。 ブラウザーはlocalhostの3000番へ入り、門番を通ってゲーム画面に届きます。

2つのコンテナの役割

同じDockerイメージから作られていますが、仕事は分けられています。

開発担当

devcontainer

  • VS Codeが接続する作業場所
  • TypeScriptとPhaserでゲームを編集
  • Viteが3000番でゲームを配信
  • プロジェクトを /workspaces/github_agent_test に共有
  • 通常ユーザー node で動作
通信担当

egress-proxy

  • PCの3000番からdevcontainerのViteへ中継
  • 外向き通信のホスト名を検査
  • HTTPSの443番だけを許可
  • 許可対象は egress-allowlist.txt で管理
  • 読み取り専用のコンテナとして動作

通信はどう流れる？

ゲーム表示と外部通信では、流れが少し異なります。

A. ゲームを見る
  1. ブラウザーがlocalhostへアクセス

    http://127.0.0.1:3000 を開きます。

  2. egress-proxyの3000番が受け取る

    PCから見える入口はプロキシだけです。

  3. devcontainerのViteへ中継

    sandbox ネットワーク内の3000番へ送ります。

B. npmなどへ接続する
  1. devcontainerから通信を開始

    プロキシ設定により直接外へ出ません。

  2. 名前とポートをチェック

    許可リストの完全一致か、443番かを確認します。

  3. 許可された場合だけ中継

    データの中身は復号せず、HTTPSのトンネルを開きます。

大切な点: devcontainerは sandbox という内部ネットワークだけに接続します。 外部側の egress へ接続できるのはegress-proxyだけです。

守りは一重ではなく、多重になっている

1つが破られても、別の層が被害を小さくする設計です。

隔壁 1：Dockerネットワーク

sandbox と egress を分離

devcontainerは外部へ直接通じない内部ネットワーク sandbox だけに入ります。egress-proxyだけが sandbox と外部側の egress の両方へ入り、 2つの区画のあいだで許可された通信を中継します。

隔壁 2：Bubblewrap

コンテナの中もさらに小さな部屋に分ける

開発コマンドごとにPID、IPC、UTS、user namespaceを分離します。 ネットワークを完全に切る --offline も使え、ホームやシステム領域も 「見える範囲」「書き込める範囲」を限定しています。

「sandboxの隔壁」とは何か: devcontainer内で動くゲームやコマンドから、直接PCやインターネットへ自由に出られないよう、 ネットワーク、Docker権限、ファイルシステム、プロセスの4方向に境界を置くことです。 egress-proxyという限定された通路を通る通信だけが外へ進めます。
① 外向き通信 sandbox には外への経路がなく、許可済みHTTPS先だけをプロキシが中継
② Docker権限 root権限・追加capability・Docker socket・特権モードを与えず、ホスト操作を遮断
③ プロセス空間 BubblewrapでPID、IPC、UTS、user namespaceを分離し、別の作業を覗けない範囲を作成
④ ファイル空間 重要設定を読み取り専用にし、信頼スクリプトをroot所有の /opt/secure-template に配置

書き込みできる場所

主にゲームのソースコード。src などの通常作業フォルダーです。

読み取り専用の場所

.git、.devcontainer、.github、.vscode、scripts。

使えない危険な操作

docker、sudo、mount、Copilot CLIの直接起動など。

実際に起動する手順

VS Codeでこのリポジトリを開き、Dev Containerで再度開くのが基本です。

  1. Docker Desktopを起動

    Dockerが動いていないと、コンテナを作れません。

  2. VS Codeで「Reopen in Container」

    devcontainer.json と docker-compose.yml の設定を読み込みます。

  3. 依存関係を導入してゲームを起動 
    npm ci
npm run dev
  4. ブラウザーで確認

    http://127.0.0.1:3000 を開きます。
